# Python Debugging

Python debugging is the process of identifying and fixing errors in a program.
- Use breakpoints to pause program execution at specific lines.
- Step Over executes the current line without entering a function.
- Step Into moves inside a function to understand its execution.
- Step Out finishes the current function and returns to the caller.
- Watch variables and inspect values to understand program behavior.
- Debugging helps identify logical errors and improve code quality.
